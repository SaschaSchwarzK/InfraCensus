Access Model

InfraCensus enforces permissions per tenant, with a global superadmin role for cross-tenant administration.

  • RO can view inventory and scan results.
  • RW can schedule scans, edit device metadata, and run exports.
  • User Admin can add/remove users and change RO/RW roles inside a tenant.
  • Superadmin can create tenants and change global configuration.
